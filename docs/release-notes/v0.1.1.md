## TL;DR

- **Fixed:** A pinned hint no longer stays on screen while the game is paused.
- **New:** The About dialog links to the Polymine repository on GitHub.

This is a small release. It fixes a hint label that showed through the Paused
screen and adds a link to the source code.

## What changed

### Playing

- When you pause, a pinned hint now disappears along with the board's cells.
  Before, its label stayed visible over the Paused screen. The hint comes back
  when you resume (#24).

### About dialog

- The About dialog has a "Source code on GitHub" link. It opens the Polymine
  repository in your browser (#27).
