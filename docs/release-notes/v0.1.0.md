## TL;DR

- **New:** Polymine is now a desktop app for Windows and macOS, with an icon and
  automatic updates from signed releases.
- **New:** Themes are folders of CSS variables, and they have their own Themes
  page with ten signature themes.
- **New:** `polymine-cli` lets scripts and coding agents play from a terminal.
- **Changed:** Datum replaces Charcoal as a theme.
- **Fixed:** A hint no longer rebuilds the board in a loop.

This is the first release of Polymine. It brings the game, its tilings, the
assistant, themes, and the command line together.

## What changed

### Playing

- The game plays on many tilings, with a solver behind the assistant.
- A hint no longer rebuilds the board in a loop.
- The window resizes in smaller steps when you use the wheel.
- A restored window now fits the work area of its monitor.

### Themes

- Themes live in folders of CSS variables. Open the Themes page to pick one.
- Ten signature themes ship with the game. Datum replaces Charcoal.
- Settings stay in place when you switch theme tabs.
- Frost no longer relaxes its cell contrast.
- Polymine refuses theme files that are hard links.

### Accessibility

- When you press the arrow keys to move between picker grids, you stay in the
  same column.

## Command line

`polymine-cli` is new. Scripts and agents can use it to play from a terminal.

```sh
polymine-cli new --tiling hexagon
```

## Platform notes

- Windows: The app icon is simpler at 16 and 24 pixels.
- Windows: The taskbar shows the theme's icon.
- Windows: Startup failures appear in a message box.
- Windows: Polymine no longer follows links in theme files.
